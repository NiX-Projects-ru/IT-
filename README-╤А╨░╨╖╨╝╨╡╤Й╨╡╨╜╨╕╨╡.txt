Это готовый одностраничный сайт: тёмный дизайн в фирменных
цветах приложения, кнопки «Скачать для Windows» и «Скачать
для Android», скриншоты, инструкция по установке и блок
партнёра NeYARO (https://ne-yaro.github.io/it-lexicon/).

──────────────────────────────────────────────────
 СОСТАВ ПАПКИ
──────────────────────────────────────────────────
index.html                — сама страница сайта (стили и иконки вшиты внутрь)
logo.png, logo-64.png     — логотип
favicon.ico               — значок сайта
shot-home.png             — скриншот: главный экран (в шапке страницы)
shot-glossary.png         — скриншот: справочник
shot-cards.png            — скриншот: флешкарты
shot-pairs.png            — скриншот: игра «Пары»
IT-Leksika-Windows.exe    — приложение для Windows (~7,5 МБ)
IT-Leksika-Android.apk    — приложение для Android (~734 КБ)

ВАЖНО: файлы EXE и APK должны лежать рядом с index.html —
кнопки скачивания ведут на них по относительным ссылкам.

──────────────────────────────────────────────────
 КАК РАЗМЕСТИТЬ НА GITHUB PAGES (бесплатно)
──────────────────────────────────────────────────
1. Создайте новый репозиторий на GitHub, например «it-lexika-site».
2. Загрузите в него ВСЕ файлы из этой папки (Add file → Upload files
   или перетащите папку целиком; файлы >25 МБ через веб-интерфейс
   загружаются нормально, EXE ~7,5 МБ подходит).
3. Откройте Settings → Pages → Source: «Deploy from a branch»,
   ветка main, папка / (root) → Save.
4. Через 1–2 минуты сайт откроется по адресу:
   https://ВАШ_НИК.github.io/it-lexika-site/

Совет: если сайт кладётся в репозиторий ПАРТНЁРА (например, в уже
существующий ne-yaro.github.io/it-lexicon/), просто положите файлы
в подпапку — все ссылки внутри сайта относительные, ничего
перенастраивать не нужно.

──────────────────────────────────────────────────
